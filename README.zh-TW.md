## 📌 支援的產品矩陣

- **[BookFun (悅讀)](https://aicrosoft.com/zh/)**：全格式統一解析閱讀器（支援 TXT、EPUB、MOBI、AZW3、DOCX、Markdown、PDF 等），具備 3D 擬真翻頁、AI 語音朗讀有聲書、Markdown 寫作排版與閱讀歷程數據統計。
- **[TrueCost Auto](https://aicrosoft.com/zh/)**：車輛持有總成本 (TCO) 智慧估算工具。涵蓋折舊、燃油/充電、保險、保養、稅費與轉售價值，協助比較電動車、油電車與燃油車的長期實際花費。
- **[FlashNote (流光筆記)](https://aicrosoft.com/apps/flashnote/zh/)**：側邊欄 Markdown 沉浸式創作工具與瀏覽器擴充功能（支援 Chrome 與 Edge），整合 AI 助理、網頁智慧剪藏、圖表與公式排版，並支援一鍵發布至靜態部落格。
- **[KinTime (家時光)](https://aicrosoft.com/zh/)**：寶寶成長歷程記錄與倒數計時工具，細緻保存成長的每一分每一秒。
- **[SavorDaily (三餐四季)](https://aicrosoft.com/zh/)**：日常飲食與料理回憶手帳，詩意留存每一刻的滋味。

## 🛠️ 支援管道與操作方式

我們主要透過 **GitHub Issues** 與 **GitHub Discussions** 提供支援：

### 1. 提交問題回報與功能建議（Issues）
若您在使用軟體時遇到異常錯誤、閃退或希望提出特定功能改善：
- **[提交 Bug 回報](../../issues/new)**：
  - 請註明產品名稱與安裝版本；
  - 填寫作業系統與裝置型號；
  - 描述問題發生的操作步驟；
  - 附上錯誤畫面截圖、螢幕錄影或紀錄檔。
- **[提交功能建議 (Feature Request)](../../issues/new)**：
  - 描述欲解決的使用情境與期待增加的功能細節。

### 2. 社群討論與使用諮詢（Discussions）
若有日常使用疑問、技巧分享或一般交流：
- **[前往 GitHub Discussions](../../discussions)**：
  - **Q&A（問答）**：操作方式提問與簡易故障排除。
  - **Ideas（靈感交流）**：分享產品改進的想法與新功能構想。
  - **General（綜合交流）**：與開發團隊及其他使用者即時交流。
