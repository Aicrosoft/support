ยินดีต้อนรับสู่ศูนย์บริการช่วยเหลือและชุมชนผู้ใช้อย่างเป็นทางการสำหรับแอปพลิเคชันและบริการดิจิทัลทั้งหมดของ **[Aicrosoft](https://aicrosoft.com/th/)**!

คลังเก็บข้อมูล (Repository) นี้จัดทำขึ้นเพื่อเป็นศูนย์รวมในการดูแลผู้ใช้ รับรายงานข้อผิดพลาด (Bugs) ติดตามข้อเสนอแนะในการพัฒนาฟีเจอร์ใหม่ และเปิดพื้นที่พูดคุยแลกเปลี่ยนสำหรับชุมชนผู้ใช้งาน

## 📌 ผลิตภัณฑ์ที่รองรับ

- **[BookFun](https://aicrosoft.com/th/) (悦读)**: โปรแกรมอ่านอีบุ๊กแบบครบวงจร รองรับไฟล์รูปแบบหลักทั้งหมด (TXT, EPUB, MOBI, AZW3, DOCX, Markdown, PDF ฯลฯ) พร้อมเอฟเฟกต์การพลิกหน้าแบบ 3 มิติ, ระบบเสียง AI อ่านหนังสือเสียง, เครื่องมือเขียนหนังสือด้วย Markdown (รองรับสูตรและแผนภาพ) และสถิติการอ่าน
- **[TrueCost Auto](https://aicrosoft.com/th/)**: เครื่องมือคำนวณต้นทุนรวมในการเป็นเจ้าของยานพาหนะ (TCO) และคู่มือช่วยตัดสินใจซื้อรถ เปรียบเทียบรถยนต์ไฟฟ้า (EV) รถไฮบริด และรถยนต์น้ำมัน โดยคำนวณค่าเสื่อมราคา ค่าน้ำมัน/ค่าชาร์จไฟ ค่าประกัน การบำรุงรักษา และราคาขายต่อในระยะเวลา 1, 3, 5 หรือ 10 ปี
- **[FlashNote](https://aicrosoft.com/apps/flashnote/th/) (流光笔记)**: เครื่องมือเขียนบันทึกด้วย Markdown บริเวณแถบด้านข้างและส่วนขยายเว็บเบราว์เซอร์ (Chrome และ Edge) พร้อมผู้ช่วย AI, ฟังก์ชันบันทึกหน้าเว็บอัจฉริยะ, แผนภาพ Mermaid, สูตร KaTeX และการเผยแพร่ไปยังบล็อกแบบคงที่ (Static Blog) ได้ในคลิกเดียว
- **[KinTime](https://aicrosoft.com/th/) (家时光)**: ตัวบันทึกพัฒนาการและเวลานับถอยหลัง เพื่อเก็บรักษาทุกนาทีและความทรงจำอันมีค่าของการเติบโตของลูกน้อยและครอบครัว
- **[SavorDaily](https://aicrosoft.com/th/) (三餐四季)**: บันทึกอาหารการกินที่เปี่ยมด้วยความรู้สึก เพื่อเก็บภาพความทรงจำเกี่ยวกับมื้ออาหารและความสุขในแต่ละวัน

## 🛠️ วิธีการรับบริการช่วยเหลือ

เราให้บริการผ่านช่องทางหลักสองช่องทาง ได้แก่ **GitHub Issues** และ **GitHub Discussions**:

### 1. การรายงานข้อผิดพลาดและเสนอแนะฟีเจอร์ (Issues)
หากพบปัญหาในการใช้งานหรือมีข้อเสนอแนะในการปรับปรุงแอป:
- **[ส่งรายงานข้อผิดพลาด (Bug Report)](../../issues/new)**:
  - ระบุชื่อแอปและเวอร์ชันที่ติดตั้ง
  - ระบบปฏิบัติการและรุ่นของอุปกรณ์ (เช่น iOS 17.4 / iPhone 15 Pro, Android 14 / Samsung Galaxy S24)
  - ขั้นตอนในการทำให้เกิดปัญหาซ้ำ
  - ภาพหน้าจอ บันทึกวิดีโอหน้าจอ หรือไฟล์บันทึกข้อผิดพลาด (Log)
- **[เสนอแนะฟีเจอร์ใหม่ (Feature Request)](../../issues/new)**:
  - อธิบายปัญหาที่พบและรูปแบบฟังก์ชันที่ต้องการให้พัฒนาเพิ่ม

### 2. คำถามทั่วไปและการพูดคุยในชุมชน (Discussions)
สำหรับการสอบถามวิธีใช้งาน แลกเปลี่ยนเทคนิค หรือพูดคุยทั่วไป:
- **[เข้าร่วม GitHub Discussions](../../discussions)**:
  - **Q&A**: ถามตอบปัญหาการใช้งานและการตั้งค่าเบื้องต้น
  - **Ideas**: เสนอไอเดียใหม่และข้อเสนอแนะด้านการออกแบบ
  - **General**: พูดคุยแลกเปลี่ยนกับผู้ใช้งานคนอื่นๆ และทีมพัฒนา
