## 📌 支持的产品矩阵

- **[BookFun (悦读)](https://aicrosoft.com/cn/)**：全格式统一解析阅读器（支持 TXT、EPUB、MOBI、AZW3、DOCX、Markdown、PDF 等，消除格式排版干扰），内置 3D 拟真翻页、多音色 AI 听书朗读、Markdown 创作写书（支持公式、图表与代码块）及阅读数据统计。
- **[TrueCost Auto (寻找最中意的车)](https://aicrosoft.com/cn/)**：车辆全生命周期总持有成本 (TCO) 智能估算工具。针对燃油车、混动车与纯电车，全方位推算折旧、能耗补能、保险、维保、税费及转售价值，支持多车横向对比。
- **[FlashNote (流光笔记)](https://aicrosoft.com/apps/flashnote/cn/)**：侧边栏 Markdown 沉浸式创作工具与浏览器扩展（适配 Chrome 与 Edge），集成 AI 助手、网页智能剪藏、Mermaid 图表、KaTeX 公式排版、专栏成书与一键直通静态博客发布。
- **[KinTime (家时光)](https://aicrosoft.com/cn/)**：成长陪伴记录与纪念日计时工具，精准留存宝宝来到世界的每一分、每一秒与关键里程碑。
- **[SavorDaily (三餐四季)](https://aicrosoft.com/cn/)**：诗意饮食日志，记录日常每一道美味与美食背后的温情回忆。

## 🛠️ 如何获取支持与操作指引

我们主要依托 **GitHub Issues** 与 **GitHub Discussions** 提供服务：

### 1. 提交异常报告与功能建议（Issues）
若您在使用过程中遇到程序异常、功能障碍或明确的产品升级建议：
- **[提交 Bug 反馈](../../issues/new)**：
  - 请注明应用名称及当前版本号；
  - 提供操作系统与设备机型（例如：iOS 17.4 / iPhone 15 Pro、Android 14 / 小米 14、Windows 11 / Chrome 124）；
  - 简述出现问题的前后操作步骤；
  - 附上报错截图、录屏或日志信息（如有）。
- **[提交功能建议 (Feature Request)](../../issues/new)**：
  - 阐述期望解决的实际业务场景或痛点；
  - 说明期望增加的新特性及其预期交互方式。

### 2. 社区互动与日常咨询（Discussions）
日常使用咨询、配置疑问或开放性交流探讨，请前往社区板块：
- **[进入 GitHub Discussions](../../discussions)**：
  - **Q&A（问答）**：日常使用操作解惑与快速排查。
  - **Ideas（灵感脑暴）**：新产品构想、设计建议与体验反馈。
  - **General（综合交流）**：与其他用户及研发团队交流互动。
